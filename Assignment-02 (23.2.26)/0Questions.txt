📝 *Question 5:  SmartProfile Finance Contract*
🎯 Contract Name: SmartProfileFinance
🔹 Requirements
Create one Solidity contract that includes:
1️⃣ Finance Section (uint & int)
uint public balance
int public profitOrLoss
Function deposit(uint amount) → Increase balance
Function updateProfit(int amount) → Update profit/loss
2️⃣ Contract Status (bool)
bool public isActive
Constructor sets it to true
Function toggleStatus() → Switch true/false
All finance functions should work only if contract is active
(Use require())
3️⃣ User Profile (string)
string public username
Function setUsername(string memory _name)
Function getUsernameLength()
Function compareUsername(string memory _other)
(Use keccak256)
4️⃣ Raw Data Section (bytes)
bytes public data
Function setData(string memory _text)
Function getDataLength()
Function getByte(uint index) with validation
5️⃣ Final Function
Create a function:
function getFullDetails()
That returns:
balance
profitOrLoss
isActive
username
🧪 Test Scenario
Set username = "Techara"
Deposit 1000
Update profit -200
Store data = "HELLO"

Try deposit again → should revert
